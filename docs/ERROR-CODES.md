# 错误识别码目录

所有用户可见错误的 message 以 `[Exxxx]` 前缀携带识别码，便于检索与反馈定位。

## 号段

| 号段 | 域 |
|---|---|
| E1xxx | 壳 / 前端（装载、IPC、更新 UI） |
| E2xxx | 插件 ABI / 插件管理器 |
| E3xxx | 硬件服务（serial / ble / uf2 / dfu / audio） |
| E4xxx | 更新与安装（包校验、签名、刷写编排） |

## 壳 / 前端（E1xxx）

| 码 | 含义 | 常见处置 |
|---|---|---|
| E1101 | 插件入口资源拉取失败 | 插件目录不完整；重新装配（`pnpm build:plugins`） |
| E1102 | 插件模块 import 失败 | 插件引用了 external 白名单外的依赖，或语法不兼容当前 WebView |
| E1103 | 插件缺少默认导出 PluginModule | 入口需 `export default definePlugin({ routes })` |
| E1104 | 插件视图渲染异常 | 看控制台堆栈；属插件 bug |
| E1105 | 插件清单枚举失败 | 壳 Rust 侧日志（`RUST_LOG=info` 重跑） |
| E1201 | 本体更新下载/安装失败 | 网络或签名问题；可重新检查 |
| E1202 | 插件更新安装失败 | 消息体内含安装管线具体码（E4xxx） |

## 插件 ABI / 管理器（E2xxx）

| 码 | 含义 |
|---|---|
| E2001 | 插件调用宿主服务失败（内文为宿主侧错误，可能含 E3xxx 码） |
| E2002 | 插件收到未知 invoke 方法 |
| E2003 | 插件收到的参数不合法 |
| E2004 | 插件处于无效状态（如未连接就写） |
| E2005 | 插件内 IO 错误 |
| E2006 | 插件内其他错误 |
| E2101–E2107 | 插件加载：IO / 清单 TOML 解析 / 动态库加载 / 缺导出符号 / ABI 不兼容 / 清单交叉校验不符 / init 失败 |

## 硬件服务（E3xxx）

| 码 | 含义 |
|---|---|
| E3100 | 串口服务通用错误（打开失败、会话不存在等，见内文） |
| E3200 | BLE 服务通用错误（适配器缺失、连接失败等） |
| E3201 | BLE 权限被系统拒绝/未授权（前端据此呈现权限通知并中止 BLE 功能直至恢复） |
| E3300 | UF2 服务通用错误（卷未找到、校验失败等） |
| E3400 | DFU 服务通用错误 |
| E3401 | DFU 串口 IO |
| E3402 | DFU 等待设备响应超时（线序/波特率/设备未进 DFU） |
| E3403 | DFU 分片 CRC 校验失败 |
| E3404 | DFU 分片长度不符 |
| E3405 | 设备返回 SMP 错误码（内文含 rc） |
| E3406 | 设备确认偏移不连续 |
| E3407 | 协议解析失败 |
| E3500 | 设备注册表错误 |
| E3601 | 音频输入设备不可用/打开失败（含麦克风权限被系统拒绝，前端据此呈现权限通知） |
| E3602 | 语音识别（STT）请求失败（网络/鉴权/响应解析，见内文） |
| E3603 | 翻译请求失败（网络/鉴权/响应解析，见内文） |
| E3604 | 翻译会话配置不合法（提供源未知、缺 apiKey、语言码非法等） |
| E3605 | 提供源响应迟缓（非致命告警，指示灯转黄；内文含实测延迟） |

## 更新与安装（E4xxx）

| 码 | 含义 |
|---|---|
| E4101 | 安装包 IO |
| E4102 | zip 解析失败（包损坏） |
| E4103 | sha256 与清单不符（下载被篡改/损坏） |
| E4104 | 包内 plugin.toml 缺失或非法 |
| E4105 | 插件要求更新的 ABI（先升级本体） |
| E4106 | 插件 id 非法 |
| E4107 | 包 id 与目标插件不一致 |
| E4108 | 包内路径不安全（`..`/绝对路径） |
| E4109 | 包内缺少当前平台动态库 |
| E4110 | 未签名包且未显式允许 |
| E4111 | 签名验签失败（非本发布渠道或已篡改） |
